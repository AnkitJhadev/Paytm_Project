# 🚀 Fullstack Monorepo (React Native + Next.js + Node.js)

A scalable production-ready monorepo built using Turborepo, featuring:

- 📱 React Native mobile app
- 🌐 Next.js web apps
- ⚙️ Shared UI + configs
- 🚀 Optimized builds with Turborepo

> Built for scalability, performance, and real-world applications.

## 🏗️ Architecture

- Monorepo managed with Turborepo
- Apps:
  - `web` → Next.js frontend
  - `docs` → Documentation site
- Packages:
  - `ui` → Shared component library
  - `eslint-config` → Centralized linting
  - `typescript-config` → Shared TS configs

### Why Monorepo?
- Code reuse
- Faster builds with caching
- Better scalability
